# Kuira Offer Links

Universal, shareable atomic-swap links for the [Midnight](https://midnight.network) blockchain —
an offer file is just text, so a private swap becomes a URL you can paste into any feed.

Built on Sébastien Guillemot's [Offer Files](https://blog.sebastiengllmt.com/posts/offer-files) design and the normative specs:

- [MIP-0005: Offer Files](https://github.com/midnightntwrk/midnight-improvement-proposals/blob/main/mips/mip-0005-offer-files.md) — the bech32m `zswapoffer1…` envelope over the canonical serialization of a **proven** Zswap offer.
- [MIP-0006: Peer-to-Peer Atomic Swaps](https://github.com/midnightntwrk/midnight-improvement-proposals/blob/main/mips/mip-0006-p2p-atomic-swaps.md) — the `OfferPayload` JSON wrapper and the REST indexer API.

## Packages

| Package | Status | What |
|---|---|---|
| `@kuira/offer-files` | ✅ | MIP-0005 codec (`encode`/`decode`/`isOfferFile`/`findAll`) + MIP-0006 `OfferPayload` types & validation |
| `@kuira/offer-store` | planned | MIP-0006 REST indexer (`POST /v1/offers`, `GET /v1/offers`, `GET /v1/health`) + Midnight liveness watcher |
| `web` | planned | Maker creation flow + universal take-page (OG cards); signs via Lace / 1AM dApp connector |
| `extension` | planned | Inline unfurler — replaces `kuira.trade/o/*` links in any page with a live offer card |

## Cross-implementation guarantee

The test suite includes fixtures generated by the Kotlin implementation in
[`kuira-android-wallet`](https://github.com/nel349/kuira-android-wallet) (`core:crypto`'s `OfferFile`):
the same deterministic 10,143-byte payload must encode to the same 16,246-character
`zswapoffer1…` string in both languages — the exact size figure the design post states.

## Notes

- Per MIP-0005, offer files **must contain proven offers only** — this codec enforces the
  envelope (HRP, checksum, no 90-char limit); proven-offer deserialization belongs to the
  Midnight ledger SDK (`ZswapOffer.serialize()` / deserialize).
- Signing and proving are delegated to the user's wallet (Lace / 1AM) via the dApp connector;
  this codebase never holds keys.
